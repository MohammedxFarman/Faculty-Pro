# Faculty Pro

Faculty Pro is an Android application designed to help faculty manage student academic records, marks, attendance, and performance analytics.

## Features

- Student Record Management
- Marks Entry System
- Attendance Tracking
- Performance Analytics
- Pie Charts and Graphical Reports
- Excel Export
- PDF Report Generation
- Gemini AI Integration

## Tech Stack

- Kotlin
- Jetpack Compose
- Room Database
- Firebase
- Gemini API
- Android Studio

## Installation

1. Clone the repository
2. Open in Android Studio
3. Sync Gradle
4. Run the application
